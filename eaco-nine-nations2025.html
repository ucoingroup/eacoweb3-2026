III文明图谱的四条主线

  • 能量线：生物质 → 化石 → 裂变 → 聚变 → 零点能。每一次跃迁都伴随社会组织形式的重写。
  • 物质线：采集 → 制造 → 打印 → 编程。物质的稀缺性逐步让位于「设计能力」。
  • 生命线：治疗 → 增强 → 编程 → 延续。伦理边界必须先于技术落地。
  • 协作线：部落 → 城邦 → 国家 → 地球村 → 星际共同体。语言与记账是协作的两条腿。
图谱不是预言，而是一张「约束清单」：它告诉你哪一步缺能量、哪一步缺信任、哪一步缺语言。

  • 每公斤载荷成本决定一切：先减重，再谈速度。

11文明经典 × EACO 地球 · 金刚经 / 易经 / 宝箧印

三部经典提供的不是「加持」，而是三套约束：怎样给而不执、怎样变而不乱、怎样存而不失。每一条都落到一个可执行动作上——不做玄学，不做价格预言，不拿经文募资。

0一句话

「应无所住而生其心」——事要真做，但心不挂在结果上。EACO 的第一条纪律正是这个：先做可验证的事，再谈价格。

1无住相布施 → 空投、赏金、水龙头

布施而不住相，意思是给出去时不附带「你以后要还我」的隐性契约。对应到 EACO：九国水龙头与翻译赏金按「交付即发」结算，公告只写规则与数量，不写涨幅、不写预期收益、不绑定持仓要求。

  • 动作：发放文案只写「做什么 / 得多少 / 怎么验」，不写「未来值多少」。
  • 边界：不做「持币生息」「拉人返佣」「保本回购」——那既是有相布施，也在多数司法辖区直接违法。

2筏喻 → 工具不是目的

「法尚应舍，何况非法」：筏子用来渡河，到岸就该放下。EACO 是筏——它解决九国之间的小额结算与协作记账，不该反过来支配人的时间、判断与生活。

  • 动作：白皮书里写死最高原则：所有文明（包括 EACO）为人类文明服务。
  • 边界：任何人以「EACO 信仰」要求你付费入会、发展下线、押上房租或学费，都是把筏子当成了岸。

3三心不可得 → 只记已发生的事实

过去心、现在心、未来心皆不可得。落到账本上：只记录链上已经发生的转账、已经交付的翻译、已经上完的课；不预支未来的承诺，也不把「计划」写成「已完成」。

  • 动作：本页所有价格都标注为「快照 + 时间戳」，而不是「目标价」。
  • 动作：月报里把「已发生」和「打算做」分成两栏，颜色不同，不许混排。

4凡所有相，皆是虚妄 → 对「市值」的态度

13地球最好的 100 个朋友 · 十类 × 十位

「100 个朋友」不是一份名人名单，而是一张可填满的矩阵：十个类别，每类十个具体角色。空位是留给真实的人——名字填进去、交付记下来，这张表才有意义。一个 EACO 小组的最低配置，是在这十类里各找到至少一个人。
① 这是资产还是费用？

买设备是资产，买流量是费用。EACO 奖励是费用还是资产，只看它有没有留下可复用的能力：译者、代码、商户关系。

② 现金流从哪来？

不来自后来入场的人，而来自真实交付：课程、翻译、商户折扣、内容授权。说不出来源的增长，都是转移，不是创造。

③ 复利在哪？

能积累的东西才复利：语言能力、代码、信任、档案。不能积累的（补贴、热度、喊单）只有一次性收益。

④ 杠杆与爆仓点在哪？

薄池 + 借贷 = 双重杠杆。先算最坏情况：如果价格归零、流动性抽干，你还剩什么？剩下的那部分，才是你的真实仓位。

14风险、合规与边界

这一节不能省。任何小组在九国落地，都绕不开下面六条。

1 · 市场风险（最硬的一条）

EACO 当前市值约 5.8 万美元、全链流动性约 600 美元、24 小时成交额常在 1 美元量级。这意味着：价格极易被单笔交易推动，也极易在无人接盘时快速回落。任何「1 厘 → 1 美元」的推演都是目标而非预测。

2 · 监管差异

美国（州级汇款牌照 / SEC 框架）、加拿大（MSB 注册）、欧盟（MiCA，法德荷适用）、日本（资金决済法 / 暗号資産交换业登记）、澳大利亚（AUSTRAC）、新西兰（FMA）、菲律宾（BSP 虚拟资产服务商）——公开募集、代币发行、法币出入金在不同辖区结论完全不同，落地前先问本地律师，不要用一国的做法套九国。

3 · 反洗钱与身份

P2P 与线下现金换币最容易踩线。保留交易记录、公开汇率、拒绝代持与代付、不与不明来源资金对接；如涉及法币兑换业务，必须做 KYC/AML。

4 · 税务

九国对加密资产的税务处理不同（持有 / 兑换 / 收款 / 空投的时点与税率都不同）。小组发放赏金、空投，需要按当地规则申报，不要用「空投不用交税」当默认假设。

5 · 别承诺收益

给新人的话术只讲三件事：这是什么、怎么免费拿到、怎么用掉。不讲「买了会涨到多少」，不做保本、回购、拉人头返利的承诺——那在多数辖区直接构成违法。

6 · 文化与语言尊重

毛利语长音符不能丢；菲律宾语不要一律当英语；加拿大法语区（魁北克）对语言极敏感，物料必须双语；新西兰手语要真人视频，不能文字冒充。语言做对了，信任才有一半。

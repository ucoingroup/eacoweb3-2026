02 · 2026-08-18 SEC：如何理解 $5M / $20M / $75M

$5M

Startup Exemption

拟议的创业融资豁免：符合条件时，四年期间累计上限 500 万美元。不是“每年 500 万”。

$20M

Fundraising Tier 1

拟议的第一层融资通道：12个月上限 2000万美元，并附有资格、披露等条件。

$75M

Fundraising Tier 2

拟议的第二层融资通道：12个月上限 7500万美元，披露、财务与持续报告要求更高。

关键理解

  • $75M 不是“SEC 给 Web3 项目的免费额度”。它是拟议监管框架中的融资上限，必须满足发行人资格、披露、财务、持续报告等条件。
  • Tier 1 / Tier 2 的 $20M / $75M 与现有 Regulation A 的两层资本形成框架存在明显对应关系。
  • Safe Harbor 的重点不是“免监管卖币”，而是针对满足条件的 crypto asset / investment contract 情形，处理关键 managerial efforts 结束后的证券属性问题。
  • Proposed ≠ Final。在最终规则生效前，不应对外宣传“EACO 已获得 SEC 允许融资 $5M/$75M”。

建议核验：SEC Newsroom（2026-08-18）、SEC Proposed Rule 文本、最终 Federal Register 公布文本及后续解释。

05 · x402 + MCP：不要重新发明标准

x402

HTTP 层的程序化支付模式：客户端请求资源 → 服务端返回 402 与支付条件 → Agent 钱包签名付款 → 再次请求 → 服务端验证并返回资源。

Agent ↓ request API ↓ HTTP 402 + price Agent Wallet ↓ sign payment Solana / USDC / EACO ↓ API verifies ↓ Service result

MCP

把 AI Agent 与工具连接起来。EACO 可以建设“EACO MCP Payment Server”，让 Agent 发现工具、读取价格并按策略自动支付。

Claude / GPT / Agent ↓ EACO MCP ↓ Tool discovery ↓ Price / policy ↓ Agent payment ↓ Tool result

战略原则：兼容 x402、Solana、MCP，而不是创造一个与主流生态隔离的新协议。

09 · 合规与融资：技术先行，融资分层

不要这样做

  • 不要宣传“SEC 已批准 EACO”。
  • 不要宣传“EACO 可以直接融资 $75M”。
  • 不要把代币升值、100倍回报作为 AI 产品卖点。
  • 不要把社区空投、贡献奖励自动当成“无证券风险”。
  • 不要把 USDC、USDT、SOL、wBNB、eCNH 的监管属性视为相同。

建议这样做

  • 美国证券律师进行 Howey / investment-contract / token taxonomy 分析。

  • 明确每笔 consideration、USD fair value、用途和投资者/贡献者身份。
  • 若未来采用拟议融资路径，分别评估 $5M、$20M、$75M 的资格与披露要求。
